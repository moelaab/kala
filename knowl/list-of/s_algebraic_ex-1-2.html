Exercise 1.
Determine which of the following statements are true and which are false.
  1. If \(\displaystyle A\) and \(\displaystyle B\) are square matrices of the same size then \(\displaystyle (A+B)^2 = A^2 + 2AB + B^2\text{.}\)
  2. The matrices \(\displaystyle A^TA\) and \(\displaystyle AA^T\) are always square, regardless of the size of \(\displaystyle A\text{.}\)
  3. If \(\displaystyle A \in \mathcal{M}_{n,m}\) and \(\displaystyle \mathbf{b} \in \mathbb{R}^m\) is a column vector, then \(\displaystyle A\mathbf{b}\) is a linear combination of the columns of \(\displaystyle A\text{.}\)
  4. If \(\displaystyle A \in \mathcal{M}_{n,m}\) and \(\displaystyle \mathbf{b} \in \mathbb{R}^m\) is a column vector, then \(\displaystyle A\mathbf{b}\) is a linear combination of the rows of \(\displaystyle A\text{.}\)
  5. If \(\displaystyle A\) and \(\displaystyle B\) are square matrices of the same size, then \(\displaystyle (AB)^T = A^TB^T\text{.}\)
